# Oddy — Your Dataverse Raven

Oddy is a Chrome side-panel assistant for Microsoft Dataverse and Power Automate. It helps you find records, understand related data, and prepare changes for review and approval, using your own Azure OpenAI connection.

## Privacy and data handling

The Oddy publisher does not operate a backend that receives your normal extension prompts or CRM data. The extension still handles information locally and sends relevant information to the Dataverse and Azure services you use.

Read the [Oddy Privacy Policy](./privacy/) for details about local storage, configured services, user controls, retention, and the Chrome Web Store Limited Use disclosure.
